{{- /* Aide à l'installation des programmes de bureau, pour un public non informaticien. Paramètres : nom (produit, requis), dossier (identifiant des données, requis), systeme (tous|windows|macos|linux, défaut tous), macos_min (version minimale de macOS, défaut 15, mesurée par la qualification du socle). Ordre : Windows, macOS, Linux. */ -}} {{- $nom := .Get "nom" -}} {{- if not $nom }}{{ errorf "aide-installation : paramètre nom requis (%s)" .Position }}{{ end -}} {{- $dossier := .Get "dossier" -}} {{- if not $dossier }}{{ errorf "aide-installation : paramètre dossier requis (%s)" .Position }}{{ end -}} {{- $systeme := .Get "systeme" | default "tous" -}} {{- $macosMin := .Get "macos_min" | default "15" -}} {{- if not (in (slice "tous" "windows" "macos" "linux") $systeme) -}}{{ errorf "aide-installation : systeme inconnu %q (%s)" $systeme .Position }}{{- end -}} {{- if eq $systeme "tous" -}}

Quel ordinateur utilisez-vous ?

  • Windows
  • Mac (puce Apple)
  • Linux (Ubuntu 24.04)
{{- end -}} {{- if or (eq $systeme "tous") (eq $systeme "windows") }}

Windows

  1. Téléchargez l’installateur Windows de {{ $nom }} (fichier se terminant par -x64.exe), puis double-cliquez dessus.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis sur Exécuter quand même. Ce message apparaît parce que le programme n’est pas encore signé numériquement ; il ne signifie pas qu’il est dangereux.
  3. L’installation se fait pour votre compte, sans droits d’administrateur. {{ $nom }} s’ouvre ensuite depuis le menu Démarrer.

Si la fenêtre reste vide ou ne s’ouvre pas

{{ $nom }} a besoin du composant gratuit de Microsoft « WebView2 », déjà présent sur la plupart des ordinateurs récents. S’il manque, ouvrez la page de téléchargement de Microsoft, téléchargez « Evergreen Bootstrapper » (ou « Evergreen Standalone Installer » si l’ordinateur n’a pas Internet), lancez-le, puis relancez {{ $nom }}.

Vos données et la désinstallation

Vos données sont conservées hors du programme, dans %LOCALAPPDATA%\{{ $dossier }}\paquet-autonome. Désinstaller {{ $nom }} (Paramètres, Applications) ne les supprime pas.

{{- end }} {{- if or (eq $systeme "tous") (eq $systeme "macos") }}

Mac

Ce programme fonctionne sur les Mac à puce Apple (M1 ou plus récent). Pour le vérifier : menu Pomme, « À propos de ce Mac », ligne « Puce ». Les anciens Mac à processeur Intel ne sont pas pris en charge. macOS {{ $macosMin }} ou plus récent est nécessaire : si besoin, installez la mise à jour dans Réglages Système, Général, Mise à jour de logiciels.

  1. Téléchargez le fichier .dmg de {{ $nom }} et ouvrez-le.
  2. Glissez l’icône de {{ $nom }} sur le dossier Applications.
  3. Ouvrez {{ $nom }} depuis Applications. Au premier lancement, macOS indique qu’il ne peut pas vérifier le programme, car il n’est pas encore signé par Apple.
  4. Ouvrez Réglages Système, puis Confidentialité et sécurité. Descendez jusqu’au message signalant que {{ $nom }} a été bloqué et cliquez sur Ouvrir quand même, puis confirmez avec votre mot de passe. Les intitulés peuvent varier selon la version de macOS. Cette étape n’est nécessaire qu’une fois.

Vos données et la désinstallation

Vos données sont conservées hors du programme, dans ~/Library/Application Support/{{ $dossier }}/paquet-autonome. Glisser {{ $nom }} dans la Corbeille le désinstalle sans supprimer ces données.

{{- end }} {{- if or (eq $systeme "tous") (eq $systeme "linux") }}

Linux

Seul Ubuntu 24.04 est qualifié. Les autres distributions peuvent fonctionner, sans garantie.

  1. Dans un terminal, installez les composants de fenêtre : sudo apt install gir1.2-gtk-3.0 gir1.2-webkit2-4.1.
  2. Téléchargez l’archive Linux de {{ $nom }} (.tar.gz) et extrayez-la entièrement : clic droit, « Extraire ici ».
  3. Ouvrez le dossier extrait et lancez le programme du même nom que {{ $nom }}, sans espaces.

Vos données et la désinstallation

Vos données sont conservées hors du programme, dans ~/.local/share/{{ $dossier }}/paquet-autonome. Supprimer le dossier extrait désinstalle {{ $nom }} sans supprimer ces données.

{{- end }}
